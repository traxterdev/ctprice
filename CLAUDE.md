# CT Price — Website

## Objetivo

Reconstruir o website atual da CT Price fora do WordPress.

Referência oficial:

https://ctprice.com.br/wp/

O novo website deve preservar com máxima fidelidade possível:

- identidade visual
- estrutura
- layout
- tipografia
- cores
- espaçamentos
- imagens
- componentes
- comportamento responsivo
- hierarquia visual
- conteúdo existente

## Regra principal

Este projeto NÃO é um redesign.

Não modernize, reinterprete ou altere decisões visuais existentes sem solicitação explícita.

O website atual é a referência visual oficial do projeto.

Sempre que uma propriedade puder ser medida ou inspecionada no site original, não estimá-la.

## Desenvolvimento

Ainda não há stack definida.

Não crie frameworks, bibliotecas, estruturas de diretórios ou dependências sem que essa decisão seja tomada durante o projeto.

## Processo

Antes de implementar uma página:

1. analisar a página original;
2. identificar sua estrutura;
3. identificar componentes reutilizáveis;
4. medir estilos e dimensões;
5. catalogar assets utilizados;
6. documentar a análise;
7. somente então implementar.

## Restrições

- Não copiar código gerado pelo Elementor como arquitetura do novo projeto.
- Não introduzir WordPress.
- Não alterar conteúdo por iniciativa própria.
- Não redesenhar componentes por preferência estética.
- Não adicionar dependências desnecessárias.
